# Jumia Black Friday Analysis

## Project Overview

This project involves Exploratory Data Analysis (EDA) of Jumia Black Friday sales data using Python. It explores patterns, distributions and trends within the dataset to generate meaningful insights through statistical analysis and data visualization.

## Objectives

- Explore and understand the dataset.
- Analyse sales and customer-related patterns.
- Identify distributions and trends.
- Generate meaningful insights through data visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Visualizations

Visual representations of the analysis include:

- Distribution plots
- Donut charts
- Statistical visualizations
